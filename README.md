## ✨ Features / 特性

- 🎨 **Glassmorphism Design** — translucent blurred panels layered over a soft animated gradient
  玻璃拟物设计 —— 半透明模糊面板叠加柔和的渐变动画
- 🧊 **Ice Blue & Lavender Palette** — a calm, low-saturation color scheme that reads well day or night
  冰蓝与薰衣草紫配色 —— 冷色低饱和，昼夜阅读都舒适
- ⚡ **Vue 3 Powered** — reactive, component-based, no heavy framework overhead
  Vue 3 驱动 —— 响应式、组件化，不堆臃肿依赖
- 🚀 **Pure Static** — no backend, no build pipeline required; just open `index.html`
  纯静态 —— 无后端、无构建流程，直接打开 `index.html` 即可
- 📱 **Responsive Layout** — adapts from mobile to ultrawide
  响应式布局 —— 从手机到带鱼屏都能看
